# Cahier des Charges - Webpick Initializr

Ce répertoire contient le cahier des charges fonctionnel et technique formel pour le projet de stage d'été (2026) chez Webpick.

## Structure du Dossier

```text
cahier des charges/
├── tex/                       # Code source LaTeX
│   ├── Cahier_des_Charges_Webpick_Initializr.tex  # Document LaTeX principal
│   └── figures/               # Logos officiels (Webpick, ENSAA)
├── pdf/                       # PDF final compilé
│   └── Cahier_des_Charges_Webpick_Initializr.pdf
├── logs/                      # Fichiers de log et intermédiaires de compilation LaTeX
└── build.bat                  # Script de compilation automatique (Windows)
```

## Compilation

Pour compiler le document de façon professionnelle (génération automatique de la table des matières et des figures) :

Exécutez le script **`build.bat`** depuis l'explorateur Windows ou via le terminal :
```cmd
build.bat
```
